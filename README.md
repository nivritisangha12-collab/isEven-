# isEven-
IsEven - A Fun Math Web App
It is a simple and humorous web application that checks whether a number is even or odd using a public API. Instead of just returning a plain result, the app displays funny and engaging responses, making math a little more entertaining.This project demonstrates API integration, JavaScript concepts, and interactive UI design.

The goal of this project is to:
- Practice working with public APIs using `fetch`
- Build a responsive and interactive UI
- Implement JavaScript concepts like array methods and event handling
- Make a boring concept (even/odd check) fun and engaging
 API Used :
- **IsEven API**  
  => https://isevenapi.xyz/  
- This API returns whether a number is even or odd along with a fun response.

- **Technologies Used**
- HTML
- CSS 
- JavaScript 
- Fetch API
